JointCam Studio 1.3.0 - Windows installer
==========================================

Download JointCam-Studio-1.3.0-Setup.exe and double-click it.
If Windows shows "Windows protected your PC", click More info, then Run anyway.
The setup is not code-signed.

On the components page you can let it download the OBS Spout2 plugin, the NVIDIA AR SDK
runtime for your GPU and OBS Studio (if missing). Already-installed parts are skipped.

Installing over an earlier version updates it in place and keeps your settings.
